---
question: Comment activer le Bonus Répar sur mes factures ?
categorie: factures
ordre: 5
mots: bonus répar, bonus réparation, ecologic, token, activer, labellisé, remise, éco-organisme
---
Le Bonus Répar est réservé aux réparateurs labellisés par Ecologic. Dans **Réglages**, ouvrez **Bonus Répar** et répondez à la question *Êtes-vous labellisé ?* Si oui, deux étapes s’affichent.

1. Appuyez sur **Écrire à Ecologic** : le message est déjà prêt, avec le nom de votre atelier et votre SIRET. Ecologic vous répond par e-mail avec votre token, un code personnel.
2. Collez-le dans **Votre token Ecologic**, cochez la case, puis appuyez sur **Activer le Bonus Répar**.

Renseignez d’abord votre SIRET dans **Statut juridique**, sans quoi le message ne peut pas partir. Une fois activé, faites vos factures comme d’habitude : la remise est déduite pour votre client et le dossier part tout seul chez Ecologic.
