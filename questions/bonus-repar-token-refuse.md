---
question: Ecologic a refusé mon token Bonus Répar, que faire ?
categorie: factures
ordre: 6
mots: bonus répar, token, refusé, ecologic, remplacer, renouveler, erreur, dossier ne part pas
---
Dans **Réglages**, **Bonus Répar** vous demande de remplacer votre token : aucun dossier ne part tant que ce n’est pas fait. Vos factures déjà faites ne changent pas.

Collez le nouveau token dans le champ de **Remplacer mon token**, puis appuyez sur le bouton **Remplacer mon token**. Vérifiez bien qu’il est complet, sans espace en trop. Il vous manque ? Appuyez sur **Écrire à Ecologic** pour en redemander un : le message est déjà prêt.

Si l’erreur revient avec un token que vous savez bon, utilisez **Si l’erreur persiste, contactez-nous** sous le champ.
